# 附录 A：虚拟卡与代办服务

## 什么样的卡能用

能绑上土区支付资料的卡，一般要满足这几条：

- 是 Visa 或 Mastercard 卡，能在海外网站付款；
- 支持 Google（Google Pay / Google Play）扣款；
- 卡里留有几美元余额，用于 Google 的小额验证扣款；
- 消费时货币是土耳其里拉，卡要支持非美元消费（通常会多收一点跨境手续费）。

!!! warning "能否绑定土区，取决于发卡方"
    很多海外虚拟卡只承诺支持美区、港区的 Google Play，绑土区资料有可能被拒。下面标注"未实测"的卡，请自行尝试；被拒的话可以换卡，或者找人代办。
